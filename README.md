## Semantic Versioning

Wir haben eine Versionsangabe mit 3 Stellen xx.xx.xx
Major.Minor.Patch
Die Major Stelle wird bei Inkompatiblen Änderungen der API (Breaking Changes) erhöht.
Die Minor Stelle wird erhöht wenn wir neue Funktionen einbauen, die abwärtskompatibel sind.
Die Patch Stelle wird erhöht bei Abwärtskompatiblen Bugfixes.

Wenn wir etwas mit npm install installieren schreib npm automatisch erstmal ein 
^ Caret vor die Version
^5.3.0 => installiert immer die neuest Version, die keinen major sprung macht
